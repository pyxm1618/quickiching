## 1. Stage boundaries

### 1.1 Public SEO V1 runtime

Public V1 的三条核心 reading path 必须 credential-free：

```text
Browser interaction
  -> shared pure casting domain
  -> shared King Wen mapping / result computation
  -> original Basic Interpretation data
  -> rendered free result
```

允许依赖：

- browser state / sessionStorage
- Web Crypto
- `Intl.DateTimeFormat` / IANA timezone data
- pure TypeScript domain algorithms
- statically bundled interpretation content

核心流程不得依赖：

- database
- auth
- payment
- credits
- AI Gateway / production model provider
- workflow service

Commercial V2 相关 `src/server`, auth, persistence, entitlement, payment, AI 等代码可以保留，但不得被 Public V1 reading path 无意加载为运行前置条件。

### 1.2 Commercial V2 runtime

未来恢复商业能力时，继续沿用原设计方向：production auth、persistent DB、question/risk lifecycle、AI deep reading、entitlements/payment、history、quality review、deletion/audit。其上线必须有独立安全与商业验收，不得反向改变 Public V1 的免费 SEO 基线。

## 2. Shared domain architecture

### 2.1 Casting types

`src/domain/casting/types.ts`

单一 `LineValue`：6 / 7 / 8 / 9。

六爻统一 bottom-up 存储：index 0 = 初爻；index 5 = 上爻。

Algorithm versions：

- `three-coin-v1`
- `yarrow-zhu-xi-digital-v2`
- `mei-hua-gregorian-current-time-v2`
- King Wen mapping: `king-wen-v1`

### 2.2 Unified hexagram result

`src/domain/casting/hexagrams/compute.ts`

所有起卦方法只负责产生六个 `LineValue`。随后统一调用：

```ts
buildHexagramResult({ lineValuesBottomUp, method, algorithmVersion? })
```

该纯函数负责：

1. yin/yang binary mapping；
2. Primary Hexagram；
3. moving positions（6/9）；
4. flip moving positions；
5. Relating Hexagram；
6. algorithm / mapping version metadata。

禁止首页、method page 或 client component 重写另一套 primary/relating 算法。

### 2.3 Browser randomness adapter

`src/lib/browser-random.ts`

- `browserRandomBit()` → Three Coin
- `browserRandomInt(maxExclusive)` → Yarrow

两者使用 `crypto.getRandomValues`。

`browserRandomInt` 使用 rejection sampling 避免 modulo bias。

`Math.random()` 不得进入 Public V1 正式起卦路径。

Node/server 侧未来仍可注入 `node:crypto` adapter，domain function 本身保持 deterministic/testable。

## 3. Three-Coin implementation

Domain：`src/domain/casting/three-coin/algorithm.ts`  
UI：`src/components/public-reading/three-coin-tool.tsx`

流程：

```text
click toss
 -> browserRandomBit x3
 -> generateThreeCoinLine
 -> immutable ThreeCoinStep appended
 -> after six steps buildHexagramResult
 -> ReadingResult
```

browser session key version化存储当前 six-line progress。用户不能单独编辑已产生的 line，只能整体 New reading。

首页直接嵌入该完整工具；`/methods/three-coin` 复用同一 component，不复制业务公式。

## 4. Yarrow implementation

Domain：`src/domain/casting/yarrow/algorithm.ts`  
UI：`src/components/public-reading/yarrow-tool.tsx`

### 4.1 Digital convention

第一变先抽样目标 removal：

- 5: 3/4
- 9: 1/4

第二、三变：

- 4: 1/2
- 8: 1/2

Domain 再枚举能够满足该目标 removal 的真实 left/right split，并通过 browser crypto 均匀选择一个 valid split。

每个 `YarrowChange` 保存：

- startingStalks
- leftGroup / rightGroup
- removedFromRight = 1
- leftRemainder / rightRemainder
- endingStalks
- lineIndex / changeIndex / algorithmVersion

Invariant：

```text
leftGroup + rightGroup = startingStalks
endingStalks = startingStalks - 1 - leftRemainder - rightRemainder
```

三变后 `endingStalks / 4` 必须属于 6/7/8/9。

### 4.2 Resume

UI 以 versioned `sessionStorage` 保存最多 18 个 change records。恢复时验证数组长度与 line/change 顺序；无效数据不继续使用。

## 5. Mei Hua current-time implementation

Domain：`src/domain/casting/mei-hua/algorithm.ts`  
UI：`src/components/public-reading/mei-hua-tool.tsx`

Convention ID：`quickiching-gregorian-current-time-v2`。

### 5.1 Time conversion

输入：`utcMillis + IANA timezone`。

`Intl.DateTimeFormat("en-US-u-ca-gregory-nu-latn", { timeZone, ... })` 转换本地 Gregorian fields。

- year branch number = Gregorian year cycle，2020 -> Zi=1
- month/day = Gregorian civil values
- 23:00 -> Zi branch and next Gregorian formula date
- 00:00 -> Zi branch on that civil date
- DST follows IANA timezone
- lunar leap month not used / not applicable

### 5.2 Formula

```text
upper = mod8(yearBranch + month + day)
lower = mod8(yearBranch + month + day + hourBranch)
moving = mod6(yearBranch + month + day + hourBranch)
```

one moving line is encoded as 6 or 9 so the same `buildHexagramResult` derives the relating figure。

UI 必须展示 convention 说明，不得用 “standard Mei Hua” 表述制造唯一正统暗示。

## 7. SEO routing architecture

Shared constants：`src/lib/seo.ts`

Canonical origin：`https://www.quickiching.com`。

Indexable routes 仅：

- `/`
- `/methods/three-coin`
- `/methods/yarrow-stalks`
- `/methods/mei-hua-yi-shu`
- `/guides/how-to-ask-the-i-ching`
- `/guides/changing-lines`
- `/guides/primary-relating-hexagrams`
- `/hexagrams`

`next.config.mjs` 处理：

- bare host -> www permanent 308
- named Vercel production alias -> www permanent 308
- legacy semantic URLs -> relevant canonical permanent 308

`src/middleware.ts` 只负责已失效/私有 pattern 的 HTTP semantics：

- obsolete commercial routes -> 410
- result/api/unknown cast routes -> 404

禁止恢复“所有无效路径 307 到首页”的 prelaunch shell 行为。

## 8. Metadata / sitemap / robots

- Root `metadataBase` = `https://www.quickiching.com`
- 首页 TDH 由 `src/lib/seo.ts` 的锁定常量提供
- 每个 indexable inner page self-canonical + distinct TDH
- `src/app/sitemap.ts` 从 `INDEXABLE_PATHS` 生成，不伪造 build-time `lastmod`
- `src/app/robots.ts` 提供 canonical sitemap，并只对 API / obsolete private product paths 做合理 crawl control
- legal/help/pricing 可以 `noindex,follow`，因此不能依赖 robots 阻止搜索引擎读取其 noindex

## 10. Quality gates

必须运行：

```text
bun install --frozen-lockfile
bun run lint
bun run typecheck
bun run test
bun run build
bun run indexnow
```

自动化需覆盖：

- Three Coin all face combinations + six-line result
- King Wen mapping / moving / relating
- Yarrow conservation + exact probability structure + golden outcomes
- Mei Hua fixed fixtures + timezone / Zi / midnight / DST edges
- 64 basic interpretation coverage
- exact homepage TDH
- sitemap / robots / canonical host constants
- legacy redirect definitions
- IndexNow URL generation
- browser E2E: desktop + small mobile, three complete readings, reset/resume, no console/network blockers

Production-like browser验收必须检查：

- initial HTML SEO content
- navigation / footer / FAQ
- no horizontal overflow at small widths
- visible state/progress
- keyboard/focus/labels
- console / network 404 / hydration
- lab performance; 不得伪造 field INP

## 11. Commercial V2 preserved architecture

以下原技术方向继续保留为未来工作，但不得成为 Public V1 import/runtime dependency：

- Better Auth / production session security
- Drizzle + PostgreSQL/Neon persistence
- question normalization/fingerprint and duplicate lock
- risk engine / safety routing
- entitlement reservation/consume/release invariants
- payment webhooks, ledger, refund/dispute reconciliation
- AI Gateway/model adapters, validation, workflow/retry/idempotency
- saved reading ownership and deletion lifecycle
- quality review/replacement-credit state machine
- analytics consent / anti-abuse / monitoring / incident readiness

未来 Commercial V2 修改共享 casting core 时，必须继续通过 Public SEO V1 domain + E2E regression gates。

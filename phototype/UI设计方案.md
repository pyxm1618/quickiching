| 维度 | 结论 |

| **受众** | 美国英语用户；对 I Ching / 东方哲学 / 塔罗 / 自我反思工具有兴趣；经 SEO（`quick i ching` 等）进入 |

**设计命题：** 现有界面是"通用 SaaS 模板"（居中 Hero + 三张图标卡片 + 系统字体），与产品的仪式感定位完全错位。用户为"一场安静的仪式"付费，界面必须先给出仪式的分量。

## 1. 设计方向：明室 · 暗室

产品体验天然分两境，设计语言据此一分为二：

```
明室 The Library                    暗室 The Chamber
────────────────────────────       ────────────────────────────
首页 / 方法页 / 教程 / 结果 / 定价   起卦仪式（三硬币 / 蓍草 / 梅花）
宣纸 #F7F2E7 · 墨色文字             暖黑 #14100A · 烛金点缀
编辑式排版，内容被"阅读"             剧场式聚焦，仪式被"完成"
```

- **明室**是书房：内容、结果、交易都在这里，要求清晰、可扫读、可信赖。
- **暗室**是仪式现场：进入起卦即换境，导航退隐，一炉微光，一次只给一个动作。明暗切换本身成为产品的记忆点——"开始起卦"像走进另一个房间。

**单一图形母题：卦画。** 阳爻一整（———），阴爻两分（—— ——），动爻染朱砂并以 ○（老阳）／×（老阴）标记。进度指示、装饰分割、结果展示全部从卦画衍生，不引入任何无关插画。

**品牌印记：方孔钱与朱砂印。** 圆形方孔钱是 logo 与加载/铸造时刻的图形；朱砂方印用于"封存、固定、认证"三类时刻（结果已封存 / 预览已固定 / 报告已交付）。

### 2.2 暗室色板（`[data-realm="chamber"]`）

| 角色 | Token | 值 | 说明 |
| --- | --- | --- | --- |
| 仪式底 | `--paper` | `#14100A` | 暖黑，非纯黑 |
| 浮层 | `--paper-raised` | `#1F1A10` | |
| 主文字 | `--ink` | `#F0E7D2` | 13.1:1 |
| 次/弱文字 | `--ink-2` / `--ink-3` | `#C9BB9C` / `#93876C` | 8.3:1 / 5.2:1 |
| 主行动 | `--cinnabar` | `#D9533A` | 提亮朱砂；按钮配深字 `#1A0E08`（5.4:1） |
| 金属 | `--bronze` | `#D9A95C` | 烛金：钱币与进度在暗处的颜色 |

**规则：**
- 语义 token 同名双值，组件只引语义名；切境 = 容器加 `data-realm="chamber"`，组件零改动。
- 禁用纯黑 `#000` / 纯白 `#FFF` / 紫蓝渐变 / 霓虹发光——全部是 AI 模板指纹。
- 朱砂只给"行动"与"封存"两类语义，不做大面积装饰，保持稀缺性。

## 3. 字体系统

| 角色 | 字体 | 用途 |
| --- | --- | --- |
| 展示 | **Fraunces**（可变，opsz） | 标题、卦名、引用；标题用 400–560 细中重 + 斜体强调 |
| 正文 | **Instrument Sans** | UI 与段落 |
| 等宽 | **IBM Plex Mono** | 数字、编号、步骤标签、版本号、价格——一切"账目感"信息 |
| 中文 | **Noto Serif SC** | 卦名汉字、印章字、文化注脚（泰 / 晉 / 九二） |

**字阶（1.333 Perfect Fourth，`clamp()` 流体）：**

```
display  clamp(2.75rem, 1.5rem+4vw, 4.5rem)   首页主标
h1       clamp(2.1rem, 1.6rem+2.2vw, 3rem)
h2       clamp(1.5rem, 1.3rem+1vw, 2rem)
h3       1.25rem      body  1rem/1.7
small    0.875rem     caption 0.75rem（mono + 大写 + 字距 .12–.16em）
```

**规则：** 英文标题禁全大写（用 Fraunces 本体）；大写只留给 mono caption。汉字以"注脚"身份出现（泰 · NO. 11 · TAI），不与英文标题混排同行。

## 4. 形状、间距与动效

- **圆角：** 印章 3px / 按钮 4px / 卡片 8px。禁用 16–24px 大圆角（玩具感）。
- **阴影：** 基本不用。层次靠纸色阶差 + 1px 界线；仅弹层允许单侧投影。
- **间距：** 4pt 基准；明室区块 64–96px 垂直留白，暗室仪式区更大（元素要"悬"在暗处）。
- **动效：**
  - 缓动统一 `cubic-bezier(0.22, 1, 0.36, 1)`（expo-out，"落定感"）；
  - UI 反馈 240ms；**卦画线条绘制 480ms（scaleX 自左向右）**；钱币落定 600ms；
  - 禁用弹性回弹缓动；`prefers-reduced-motion` 全局降级（已在 tokens 内置）。

## 5. 签名组件规范

### 5.1 `<HexagramLines>` 卦画（核心）
- 六爻**自下而上**构建，自上而下展示；每爻一行：爻题（初九/九二…，mono 小号）+ 爻形 + 动爻标记。
- 阳爻整段，阴爻两段（中间留 12% 缺口）；动爻段染 `--cinnabar` 并在尾端标记 ○/×。
- 三档规格：`lg` 190px（结果页主展示）/ `md` 96px（历史列表）/ `sm` 34px（变卦缩略、装饰）。
- **仪式进度即卦画**：暗室中六爻槽位以 1.5px 虚线预显，每成一爻实线落定——进度条与结果是同一个东西。

### 5.2 `<CoinMark>` 方孔钱
- 圆环古铜渐变 + 中央方孔（径向渐变仅用于金属，不用作界面背景）。
- 三硬币仪式中：字面显示「乾」字（heads=3），背素面（tails=2），右侧 mono 算式 `3+2+2 = 7 · YOUNG YANG`。

### 5.3 `<SealMark>` 朱砂印
- 3px 圆角方印，白字；用字：易（品牌）/ 封（结果封存）/ 固（预览固定）。
- 可微转 −6°~+6° 模拟手盖感；每屏最多一枚。

### 5.4 卦画分割线 `.hex-divider`
- `———  —— ——`（阳爻接阴爻）替代通用 `<hr>`，用于内容页章节分隔。

### 5.5 按钮 / 卡片 / 表单
- **主按钮**仅每屏一个（朱砂）；次动作为青玉文字链；危险操作走 `--danger`。
- **卡片**：`--paper-raised` + 1px `--line` + 8px 圆角，无阴影；hover 仅 1px 抬升（translateY）。
- **表单**：44px 触控高度，focus 2px 朱砂描边 + 2px 偏移；字符计数用 mono。

## 6. 页面级设计

### 6.1 首页（明室 · 编辑式）
- 左文右卦双栏 Hero：左为 Fraunces 主标（斜体朱砂强调价值词）+ 单一主 CTA「Start Your Coin Reading」；右侧立一卦「泰」作为氛围展品（编号 + 上下卦构成注脚）。
- 巨大淡印「易」字水印为背景肌理（opacity ≤ .05）。
- 三方法以**书页栏**（非图标卡片）排开：mono 序号 01/02/03 + 英文名 + 中文注脚 + 一句话 + 青玉链接。
- 页底三步承诺条（Ask → Ritual → Reveal），mono 罗马数字步骤。

### 6.2 起卦仪式（暗室 · 剧场式）
- 全页 `data-realm="chamber"`；顶栏缩为一行 mono 小字（方法名 + "Question sealed ✓"）。
- 中央单列：场景/目标 chip 回顾 → 轮次 caption（ROUND 4 OF 6 · 第四爻）→ **生长中的卦画** → 上一轮三币与算式 → 唯一主按钮「Cast the fourth line」。
- 底部一行 mono 保证书：「Each line is sealed the moment it is cast · 不可撤销 · 不可重来」——不可逆性（CAST-002）用文案与氛围双重传达。
- 蓍草法同构：18 步改为三变一组的爻内小节拍，卦画同样逐爻落定。
- 移动端：列宽收窄，按钮全宽 100%，卦画保持 190px 不缩水。

### 6.3 结果页（明室 · 碑刻式）
- 左栏大规格卦画卡（lg）+ 动爻统计 + 「Changing toward」变卦缩略条；右栏：编号（mono）→ 卦名 Fraunces + 汉字 → 上下卦构成 → 卦辞引用块（左边框朱砂 + 斜体）→ 固定预览卡（盖「固」印）→ 深墨底深度解读 CTA。
- 无动爻时明确写「No moving lines — read as stable」，不伪造变卦（PRD §10.1）。

### 6.4 定价页（明室 · 账册式）
- 三栏账册并列（非孤立卡片墙），总价 Fraunces 大数字 + mono 单次折算；
- 「Best Value」用朱砂描边印章斜盖，不用荧光角标；
- 页脚 mono 小字写清 12 个月有效期与 FIFO 规则——克制陈述，禁止倒计时/划线价（PRD §13.1）。

### 6.5 内容/教程页（明室 · 书卷式）
- 正文栏宽 65ch，居中；Fraunces 章节题 + `.hex-divider` 分隔；首段可落首字下沉（drop cap）；方法规则用 mono 表格呈现（3/2 计数、6/7/8/9）。

### 6.6 安全与异常页
- 紧急阻断页（crisis）：明室浅底 + 左朱砂边条，988/911 信息用最大可读性排版，无任何品牌装饰——安全时刻退出设计语言。
- 专业决策阻断：青玉边框卡，区分"可保留卦象"与"不可生成解读"两个动作。

## 7. 无障碍（WCAG 2.1 AA，内建于 tokens）

- 全部文字/背景组合 ≥ 4.5:1（上表已逐对核算）；
- 焦点环 2px 朱砂（暗室烛金）+ 2px 偏移， `:focus-visible` 全局生效；
- 触控目标 ≥ 44px；卦画提供 `aria-label`（如 "line 2, yang, moving"），动爻不靠颜色单独传达（○/× 符号 + 文字双重编码）；
- 动效尊重 `prefers-reduced-motion`。

---

## 8. UX 文案原则（配合 PRD 英文文案）

- 仪式相关动词用庄重词：Cast / Seal / Reveal，不用 Spin / Toss / Play；
- 不可逆说明陈述事实，不警告恐吓：「Each line is sealed the moment it is cast.」；
- 付费承诺复述 PRD §11.1：「A fixed, re-openable report written for this exact situation.」；
- 错误状态必须给下一步（对应 PRD §14.2 状态表），禁止裸「Something went wrong」。
